Access

Who can see what

A member request has no field that can point at another person. The script decides whose data to return from the signed-in session, and the director role is read from the sheet, never from the browser. Automated tests try to read, edit and delete another member's entries, and every attempt is refused.

Work mode

In office, WFH or On leave

Each member ticks one option per day on their own page. It takes one click, can be changed or cleared, and can be set for any day in the last 7.

In office

Counted as a normal working day.

WFH

Counted as a normal working day. Shown with a charcoal dot on the director's heat map.

On leave

Taken out of capacity, so the member is never flagged as low load for that day.

Who sees it

The member sees their own days. The director sees today's attendance for the whole team and every day in the reports workbook.

Capacity is 8 hours per working day, minus any day ticked On leave. Utilisation is hours logged divided by capacity. Above 110 percent is flagged over capacity, below 60 percent is flagged low.

Google Sheets and Excel

The reports workbook

A separate, branded spreadsheet the director can open, download as Excel, or share view-only. It refreshes every hour, and the MIB Workload menu in the data sheet refreshes it for this week, last week, this month or the last 30 days.

Dashboard

Four headline figures, workload by member with flags and office, WFH and leave days, category and status split, hours per day, and three charts.

Monthly

Hours per member per month for 12 months. Darker cells mean more hours.

Attendance

Office, WFH or leave for every member and day of the period.

All entries

Every entry as a flat table with a filter on each column. The tab to export.

Read me

Definitions for capacity, utilisation, flags and hours, plus export instructions.

Excel (.xlsx)

Reports workbook, File > Download > Microsoft Excel. The MIB Workload menu also gives a direct link. Formatting and load bars carry over; charts usually convert to Excel charts.

CSV

Website, director view > Entries > Export CSV. Or All entries tab > File > Download > CSV.

Google Drive

Connect a Google Drive

  1. Use a Google account only you control

    A fresh account keeps MIB data apart from personal files. Its Drive will hold everything.

  2. Create the sheet

    Drive > New > Google Sheets. Name it MIB Workload Log. Do not share it.

  3. Add the two script files

    Extensions > Apps Script. Paste Code.gs. Then + > Script, name it Reports, paste Reports.gs. Save.

  4. Run setup

    Run setup and accept the permission prompts. It creates the Attendance tab and the admin account for Bireshwar Chakravarty. The first password appears on the Credentials tab.

  5. Add the team

    Fill the Roster tab with name and role, run createUsersFromRoster, hand out the passwords privately, delete the Credentials tab.

  6. Turn on reports and backups

    Run installTriggers once. Reload the sheet to see the MIB Workload menu.

  7. Publish the script

    Deploy > New deployment > Web app. Execute as Me, access Anyone. Copy the URL.

  8. Point the website at it

    Put the URL in frontend/config.js as API_URL and push to main. The site redeploys on its own and leaves demo mode.

  1. Copy the data sheet into the new account

    File > Make a copy into the new Drive. A copy brings both script files with it.

  2. Check the scripts

    Extensions > Apps Script. If you uploaded an .xlsx instead of copying, paste Code.gs and Reports.gs again.

  3. Turn on reports and backups

    Run installTriggers. Triggers do not move with a copy. The first refresh creates a new reports workbook.

  4. Publish the new script

    Deploy > New deployment > Web app, Execute as Me, access Anyone. Copy the new URL.

  5. Update the website

    Replace API_URL in frontend/config.js and push to main.

  6. Tell the team to sign in again

    Accounts and passwords carry over in the Users tab. Only sessions reset.

  7. Retire the old account's copies

    Archive the old deployment, then delete the old sheet, its backups and its reports workbook.
